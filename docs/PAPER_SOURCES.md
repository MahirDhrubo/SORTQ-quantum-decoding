# Paper sources: where each number comes from

Detailed map from each result to the files and scripts that produce it (the README has the short version by paper table / figure). Here `Fig. 6` is the script name of the paper's Fig. 8 (`scripts/fig6.py` -> `figures/fig_results.pdf`). Per-shot traces (`*.npz`) and shot sets are not in the repository; they are regenerated by the scripts named. All paths are relative to the repository root. Kinds:
- **trace:** per-shot decoder output.
- **sim:** RTL simulation.
- **synth:** Vivado post-route.
- **derived:** computed from the others; the script is named.

## Reproduction order
1. Environment, circuits and samples: `archive/ENVIRONMENT.md`, `archive/env/`, `archive/patches/`, `archive/circuits/`, `archive/shots/` (`scripts/archive_shots.py`, `archive_shots2.py` regenerate and verify them).
2. Traces: `scripts/run_test1b.sh`, `run_test1f.sh`, `run_test1g.sh`, `run_test1g_p001.sh`, `run_test1h.sh`.
3. Criteria: `test1e_criteria.py`, `test1f_criteria.py`, `test1g_criteria.py`, `test1g_criteria_p001.py`, `test1h_criteria.py`, `test1h_criteria_robust.py`.
4. Tables: `eval_accuracy.py`, `test1h_report.py`, `test2d_model.py` (REF_RUN / OUT_SUB as above), `sortq build` (SORTQ_REF_RUN = pf2fix; `--order rb`, the default, also writes the red-black package), `eval_scaling.py`.
5. Figure: `fig6.py`, which re-runs `eval_scaling.py`.
