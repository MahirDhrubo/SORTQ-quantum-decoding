- **Provenance of the 12-round and [[72,12,6]] circuits** (checked 2026-11-16):
  - The `bb_ibm` files are IBM's Relay-BP test circuits (https://github.com/trmue/relay, `tests/testdata/bicycle_bivariate/`, Apache-2.0, © IBM), with one change: the final data measurement `M[disable_noise]` is written as plain `M`.
  - Stim treats tags as annotations. All 42 `bb_ibm` files have the same name, line count and detector error model as IBM's copies.
  - Sampling IBM's own files with our sampler configuration reproduces the archived shots bit for bit (first call of each 12-round set: 0 detector and 0 observable bits differ).
  - The artifact can therefore cite and use IBM's circuits directly.
- **36-round circuits:** generated by `circuits/make_bb_ibm_rounds.py` (Test 1d prep, 2026-11-12). It splices more identical rounds into the IBM circuit and rebuilds it.
  - Rebuilding R = 12 reproduces the original files byte for byte at p = 0.001, 0.002 and 0.003 (`results/test1d_prep/summary.md`).

## Shot sets (sampler configuration)
- **Every set:** `sampler = circuit.compile_detector_sampler(seed=SEED)`, then `det, obs = sampler.sample(n, separate_observables=True)`, with n = batch × workers per call (the last call takes the remainder).
- **Stim's samples depend on the call sizes** (measured: `sample(2000)` ≠ the first 2,000 of `sample(4000)`), so batch × workers is part of each set's definition.

| Set (archive file) | p | Seed | Shots | Batch × workers = call size | Calls | Used by |
|---|---|---|---|---|---|---|
| `shots/p0.003_seed20261111.npz` | 0.003 | 20261111 | 168,000 | 500 × 8 = 4,000 | 42 | Tests 1b, 1f, 1g, 1h steps 1 / 3, eval accuracy |
| `shots/p0.002_seed20261111.npz` | 0.002 | 20261111 | 600,000 | 1000 × 8 = 8,000 | 75 | Tests 1b, 1f, 1g, 1h step 3, eval accuracy |
| `shots/p0.001_seed20261111.npz` | 0.001 | 20261111 | 600,000 | 1000 × 8 = 8,000 | 75 | Tests 1b, 1f, eval task 2 (rb13), eval accuracy |
| `shots/p0.003_seed20261120.npz` | 0.003 | 20261120 | 168,000 | 500 × 8 = 4,000 | 42 | Test 1h step 2 (fresh shots) |

- **Files** (`scripts/archive_shots.py make`; metadata, file sha256 and circuit sha256 in the matching `.json`):
  - `det_packed` [shots × 216] and `obs_packed` [shots × 2] are `uint8`, from `np.packbits(axis=1, bitorder="little")`. Bit j of a row is detector or observable j.
  - Also stored: `num_detectors`, `num_observables` and `z_rows`.
  - Unpack with `np.unpackbits(x, axis=1, count=n, bitorder="little")`.
- **Verification** (`archive_shots.py verify`; `shots/verify.json`, `verify.log`): the first 2,000 shots of each set were re-decoded with `the relay_bp environment`. Iterations, success and logical failure differ on **0 shots** in all 11 comparisons:

  | Set | Decoders compared with existing traces |
  |---|---|
  | three seed-20261111 sets | float flood and int4.2.8 sweep (Test 1b); rb13 int4.2.8 (Test 1g; eval p = 0.001 run) |
  | seed 20261120 | float flood, rb13 int4.2.8 (Test 1h step 2) |
