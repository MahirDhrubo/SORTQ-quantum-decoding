# Test 2a testbenches

Simulator: **Verilator 5.054** (conda-forge, private env `the HDL environment` on the server; Icarus 13.0 is installed there
too but not used). Build: `verilator --binary --timing -j 4`.

| Script | What |
|---|---|
| `run_tb.sh <tb> [-Gparam=v ...]` | build + run one testbench (`RTL=<dir>` overrides the RTL folder) → `logs/<tb>[_params].log` |
| `tb_round_step`: `-GVNU_PASSES=1/2`, run-time `RUNARGS="+VEC=... +PTAB=..."` (default 3-shot vectors + `vectors/prior_table.txt`) | |
| `run_all.sh` | final regression of every testbench on `../rtl` → `logs/regression.txt` |
| `mutate_par.sh m1 .. m4` | up to 4 mutants in parallel, 1 build job each (`OBJTAG`, `JOBS` in run_tb.sh) |
| `mutate.sh` | one realistic bug per block in a copy of the RTL; each must make its testbench FAIL → `logs/mutation*.log` |
| `gen_vectors_step3.py` | conv_check / ctrl / commit vectors from the 36-round H and O |
| `gen_vectors_round.py` | full round-step vectors from the golden dumps |
| `gen_vectors_random.py` | random CNU / VNU vectors from the ARITHMETIC.md model (used for N = 6) |
| `../golden/check_and_vectors.py` | checks the dumps against ARITHMETIC.md and writes `cnu_vectors.txt`, `vnu_vectors.txt` |
| `../gen/labels.py` | engine coordinates of H rows / columns; writes `round_wiring_expected.txt` from H |

Vector files live in `vectors/` (on the server only; ~1 GB, regenerated by the scripts above):
- `cnu_vectors.txt`: `syn mask[35] in_sign[35] in_mag[35] out_sign[35] out_mag[35]` (decimal; invalid slots = junk)
- `vnu_vectors.txt`: `init prior g8 mpost mask[6] late[6] c2v_stored[6] bias marg hard v2c_out[6]`
- `round_wiring_expected.txt`: `x k o idx p`
- `conv_vectors.txt`, `ctrl_expected.txt`, `commit_vectors.txt`, `round_vectors.txt`: hex packed vectors, formats in
  the generator docstrings.
