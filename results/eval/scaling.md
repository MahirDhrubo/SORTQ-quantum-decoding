# Scaling: SORTQ red-black engine vs fully parallel, logical qubits per FPGA

Generated by `scripts/eval_scaling.py` (estimates from measured blocks; no new synthesis).

## Setup
- **Reference engine (measured):** engine_top_rb (tc/A_explore_4.76), gross-code X decoder, post-route on xcvu19p: **520,369 LUT**, 140,289 FF, 37,868 LUTRAM, **210.1 MHz**, 13 cycles = **61.88 ns per 13-round iteration**.
- **Per-block breakdown** from that run's hierarchical report (sum 520,400 LUT; calibration 0.99994 to the measured total):

  | Block | LUT | LUTRAM | FF | Scaled by |
  |---|---|---|---|---|
  | round_step | 382,174 | 0 | 102,823 | sortq round_step model (CNU + VNUs per position + glue) |
  | memories | 62,723 | 37,868 | 0 | rb state bits per home round (memory width) |
  | gamma_lanes | 46,815 | 0 | 14,400 | NT × NPOS |
  | conv_check | 22,609 | 0 | 1,125 | W × NPOS × NBASE |
  | commit | 5,288 | 0 | 180 | NT × NPOS × NOBS |
  | ctrl | 711 | 0 | 225 | constant |
  | glue | 80 | 0 | 21,536 | constant |

- **Assumptions (stated):**
  - **Window:** W = number of detector rounds (7 / 13 / 19), one window over the whole circuit. This is how the rb engine was built and measured (W = 13, win_t = 0 asserted). The sweep-engine numbers keep W = d (6 / 12 / 18) from Test 3f.
  - **Memories scale with width, not depth:** each parity bank holds ⌈W/2⌉ words (4 / 7 / 10), and the LUTRAM primitives are 32 deep, so the measured cost (7 words) depends on the bits per word. (The Test 3f sweep model scaled memories by bits × W; those numbers are kept unchanged.)
  - **Same per-position content:** all six decoders have 10 error types (7 two-round), 35 base edges and the same type weights. So the round step scales with the number of positions (36 / 72 / 144), and X and Z engines get the same estimate.
  - **Clock:** measured for the gross X engine only. The ns figures for other codes use the same clock, which is an assumption, not a measurement (the 288 engine has twice the positions).
  - **Code block** = X engine + Z engine, each complete. Budget ≤ 80% of 4,085,760 LUT = 3,268,608. k = 12 logical qubits per block.
  - **Fully parallel** = Σ CNU(deg) + Σ VNU(deg) over the whole decoder matrix from our standalone blocks (Test 2d / 3f), one basis.
